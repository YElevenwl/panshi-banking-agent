## 四、复现方式

```bash
unzip 03-源代码与部署材料.zip -d panshi-bank-agent
cd panshi-bank-agent
node src/server.js
```

打开 `http://localhost:8787`，演示账号 `user_1001` 林晓。运行时零依赖，无需 `npm install`；要求 Node.js ≥ 24。

```bash
npm test                 # 44 项单元 + 集成测试
npm run adversarial      # 18 条安全对抗
npm run eval             # 3 个核心场景各重复 20 次
npm run audit:verify     # 审计哈希链校验
```

## 八、诚实声明

- 演示环境为沙箱模拟，账户、余额、交易均为虚构数据，不涉及真实资金。
- TOTP 用于模拟 FaceID / WebAuthn 强验证；生产环境应替换为真实生物识别与设备绑定。
- 银行核心为本地 SQLite 模拟账本与 24 个受控工具，未接入真实银行生产 API。
- 真实模型对照使用公共匿名端点 GPT-OSS-20B，受 1 reply/45s 限流；正式评测应使用银行批准的模型端点与 Key。
- Docker 构建、GitHub 远程仓库、gVisor 通用代码沙箱尚未在本机验证，已在 `04-安全自评报告.pdf` 中如实标注。
